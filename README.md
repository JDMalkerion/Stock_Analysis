# Stock Analysis Project

## Overview

This repository contains a **complete end‑to‑end analysis of six NSE stocks** (Bajaj Auto, Eicher Motors, Hero Motocorp, Infosys, TCS, TVS Motors) covering the period **2015‑01‑01 to 2018‑07‑31**.  The workflow:

1. **Load CSV data** into a local SQLite database (`data/stocks.db`).
2. **Compute derived series** – moving averages, golden‑cross signals, adjusted price series for two bonus‑issue events (TCS 2018‑05‑31, Infosys 2015‑06‑15).
3. **Run a suite of analytical SQL queries** (`sql/01_*.sql` … `sql/16_*.sql`).
4. **Generate a richly‑styled insights report** (`reports/insights.md`) with supporting charts (`reports/images/`).
5. **Verify every claim** automatically with an independent Python script.

All numbers in the report are **computed at build time** from the database – no manual entry.

## Getting started

### Prerequisites

* **Python 3.11+** (standard library includes `sqlite3`).
* **matplotlib** – used for chart generation.

Install the required Python package:

```bash
cd /home/JDCypher/Projects/Stock_Analysis
pip install --quiet matplotlib
```

### Load the data

```bash
python3 src/load_sqlite.py
```
The script drops any existing tables and recreates six tables (`bajaj_auto`, `eicher_motors`, …) populated from the CSVs in `data/`.

### Run the full analysis pipeline

```bash
# 1️⃣ Generate the markdown report and PNG charts
python3 src/make_report.py

# 2️⃣ Verify every figure, table and image link
python3 src/verify_report.py
```
If the verification script prints `Results: 113 PASS | 0 FAIL` you are good to go.

## Key findings (from `reports/insights.md`)

| Finding | Summary |
|---|---|
| **Performance leaders** | TVS Motors (+86.9 %) and Eicher Motors (+82.6 %) delivered the strongest adjusted price gains. |
| **Price‑adjustment events** | TCS and Infosys each experienced a ~50 % overnight drop on the event dates; adjusting the series flips their overall returns from negative to positive (TCS +52.4 %, Infosys +38.2 %). |
| **Golden‑cross rule** | 54 Buy‑Sell round trips were generated; 21 were profitable. Eicher Motors was the only stock with **all** trips winning (6/6). |
| **Whipsaws** | 34 consecutive signal pairs occurred within 30 calendar days; 11 of those formed round trips and **10 lost money**. |
| **Method limitation** | The moving‑average crossover cannot fire before 50 trading days have elapsed, imposing a structural lag on signal generation. |

The full narrative, tables, and visualisations are in the markdown report.

## Re‑producing the report from scratch

1. **Clear any existing DB** (optional):
   ```bash
   rm -f data/stocks.db
   ```
2. **Load CSVs** – `python3 src/load_sqlite.py`.
3. **Run any intermediate task** (e.g., `python3 src/run_task10.py`) if you wish to examine raw query output.
4. **Create the final report** – `python3 src/make_report.py`.
5. **Validate** – `python3 src/verify_report.py`.

All artefacts (`reports/insights.md`, PNGs, the SQLite DB) are committed to the repository for reproducibility – the `.gitignore` only excludes the raw CSVs and any future temporary DBs you may generate.
